# 哔哩哔哩下载器（BILI）

一个本地运行的 B 站视频下载工具：输入 BV 号 → 解析视频信息 → 后台多线程下载视频流与音频流 → 用 FFmpeg 合并为 MP4。提供 Web 界面（Flask）与命令行脚本两种使用方式。

## 功能特点

- **BV 号 / 视频链接自动识别**：粘贴完整链接也能自动提取 BV 号。
- **视频信息解析**：点击「解析视频」获取标题，确认无误后再下载。
- **灵活的分P选择**：支持 `1`、`1-3`、`1,3,5-7` 等写法，单个范围最多 200 P。
- **图形化选择保存目录**：调用系统原生文件夹选择器（依赖 `tkinter`）。
- **实时进度推送**：基于 SSE（Server-Sent Events）显示当前分P、阶段、百分比与已完成文件列表。
- **异步任务队列**：`ThreadPoolExecutor(max_workers=2)`，最多 2 个下载任务并发。
- **自动合并与清理**：FFmpeg 完成音视频合并后，可选择删除临时文件。
- **文件名安全处理**：自动过滤非法字符，长度截断至 100 字符。

## 环境要求

- Python 3.9 及以上
- **FFmpeg**：必须安装并加入系统 `PATH`（音视频合并依赖它）
  - Windows 可从 <https://ffmpeg.org/download.html> 下载，解压后将其 `bin` 目录加入环境变量
  - 验证：终端执行 `ffmpeg -version` 能正常输出版本号
- `tkinter`：用于「浏览...」文件夹选择器，通常随 Python 官方发行版一同安装

## 安装与启动

```powershell
cd c:\BILI

# 1. 创建虚拟环境（推荐）
python -m venv .venv
.\.venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python app.py
```

启动后访问 <http://127.0.0.1:5000> 即可使用。

## 使用说明（Web 界面）

1. **BV 号**：填入 `BV1xx411c7mD` 或粘贴完整视频链接，点击「解析视频」确认标题。
2. **保存目录**：手动填写，或点击「浏览...」在弹窗中选择。
3. **下载分P**：如 `1`、`1-3`、`1,3,5-7`。
4. **文件名前缀**：留空则使用 BV 号，例如填 `课程-` 会生成 `课程-1_out.mp4`。
5. **输出设置**：默认勾选「合并完成后删除临时音视频文件」。
6. 点击「开始下载」，下方进度卡片实时显示 `阶段 / 已完成P数 / 总体进度`，完成后列出所有输出文件路径。

### 输出文件命名

合并产物为 `{前缀}{分P号}_out.mp4`，例如前缀 `课程-`、第 2 P → `课程-2_out.mp4`。

## 使用说明（命令行脚本）

`爬取b站视频.py` 为交互式命令行版本，无需启动 Flask：

```powershell
python 爬取b站视频.py
```

按提示依次输入：

| 提示 | 说明 |
| --- | --- |
| `BV:` | 输入 BV 号，输入 `0` 退出循环 |
| `name:` | 文件名前缀 |
| 保存路径 | 留空则保存在当前目录 |
| 要下载的p数 | 如 `1`、`1-2`、`1,3,5` |
| 是否删除合并前文件 | `1` 是、`0` 否 |
| 是否整合为文件夹 | `1` 是、`0` 否（以 name 创建子目录并移入） |

## API 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/` | Web 首页 |
| `POST` | `/api/parse` | 解析 BV 号，返回视频标题 |
| `POST` | `/api/select-directory` | 打开本机文件夹选择器，返回所选路径 |
| `POST` | `/api/tasks` | 创建下载任务，返回任务对象（HTTP 202） |
| `GET` | `/api/tasks/<task_id>` | 查询任务状态 |
| `GET` | `/api/tasks/<task_id>/events` | SSE 实时推送任务进度 |

任务对象字段：`id`、`status`（`queued`/`running`/`completed`/`failed`）、`stage`、`title`、`current_part`、`part_progress`、`completed_parts`、`total_parts`、`files`、`error`。

## 常见问题

- **提示「没有找到视频播放信息」**：可能需要登录的会员视频、B 站页面结构变更，或被风控拦截。脚本未处理登录 Cookie。
- **提示「FFmpeg 合并失败」**：确认 FFmpeg 已安装且 `ffmpeg` 命令可在任意目录执行；可重启终端使环境变量生效。
- **「浏览...」按钮报错**：当前 Python 未安装 `tkinter`，可手动填写保存目录。
- **下载速度慢或中断**：B 站对视频流有 Referer 校验与限流，脚本已携带正确的 `Referer` 与 `User-Agent`，可稍后重试。
- **仅取第一条视频/音频流**：当前实现选取清晰度列表中的第一项，未做清晰度选择。
